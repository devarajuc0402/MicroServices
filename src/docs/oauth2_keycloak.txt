Steps to initiate:
================================================================================================
1. Open power shell
================================================================================================
2. execute on docker
docker run --name keycloak `
  -p 8180:8080 `
  -e KC_BOOTSTRAP_ADMIN_USERNAME=admin `
  -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin `
  quay.io/keycloak/keycloak:26.8.0 `
  start-dev
================================================================================================
3. install on local system: 
================================================================================================
4. Create Keycloak realm:
	-Open : http://localhost:8180
	-Username: admin
	-Password: admin
	-Create realm name: microservices
	-Open and check the details: http://localhost:8180/realms/microservices
	-OpenID metadata: /realms/microservices/.well-known/openid-configuration
================================================================================================
5. Create user:
	-Under realm microservices: left menu
	-Select Users
	-Username: testuser
	-Email: test@noemail.com
	-Email verification: Enable
	-Click create
	-Select Credentials
	-Password: test123
	-Temporary: OFF
================================================================================================
5. Create client:
	-Left menu
	-Select Clients
	-Click on create client
	-CLient Type: 
	-Client ID: microservices-client
	-Name: microservices-client
	-Description: microservices-client
	-NEXT
	-Client authentication: ON
	-Authorization: OFF
	-Standard flow: ON
	-Direct access grants: ON
	-Implicit flow: OFF
	-Service accounts roles: OFF
	-NEXT
	-Root URL: Empty
	-Home URL: Empty
	-Valid redirect URIs: Empty
	-Valid post logout redirect URIs: Empty
	-Web origins: Empty
	-Admin URL: Empty
================================================================================================
6. Generate Token:
	-Generate the token:
		-Open postman: 
			-POST
			-URL: http://localhost:8180/realms/microservices/protocol/openid-connect/token
			-Body
			-x-www-form-urlencoded
			-client_id=microservices-client
			-grant_type=password
			-username=testuser
			-password=test123
================================================================================================
7. Can Increase token TTL:
	-Default: 5 minutes
	-To Increase:
		-Left menu click Realm settings
		-Click on Tokens
		-Access Token Lifespan - mention like 30 minutes
		-Save
================================================================================================
8. Create role:
	-Left menu
	-Click Realm roles
	-Click create role
		-Name: USER, ADMIN, HELP, KAFKA, REST
		-Description: user role 
		-Associated roles: empty
		-Attributes: empty
		-Users in role: [as of not required] which user needs this user access 
		-Admin events: empty
		-Spring convert Authority roles: ROLE_ADMIN ...
	-Map Roles to user:
		-Click Users
		-Click Role mapping
		-Assign role --> Realm roles
		-Select all roles [USER, ADMIN, HELP, KAFKA, REST]
		-Assign
================================================================================================
9. Note: Roles:
	-Roles mapped with token no need to add anywhere
	-Once created role and mapped with user in keycloak dashboard can use it
================================================================================================
